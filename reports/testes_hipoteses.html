1 Objetivo e regras

Fase 2 do enunciado (Hypothesis testing): para cada hipótese, indicar H0 e HA, justificar o teste e os seus pressupostos, e interpretar o resultado com o tamanho do efeito e a sua incerteza (intervalo de confiança a 95%). Os dados são observacionais, por isso os resultados mostram associações, não causas.

  • Só dados de desenvolvimento (2007-06 a 2014-12). O teste final (2015) nunca é usado.
  • As hipóteses sobre o default usam o treino da classificação (empréstimos de 36 meses de 2007-06 a 2011-12): é o único conjunto em que o desfecho de cada empréstimo já era conhecido na data de treino simulada.
  • Os dados vêm de notebooks/02b_dados_testes_hipoteses.ipynb, que os exporta sem alterar nenhum valor.
  • Não há transformações aprendidas (imputação, escalamento, etc.): os testes usam os valores limpos tal como estão. Por isso não é preciso um pipeline em R.

Tamanho da amostra e p-valores. Com dezenas de milhares (ou milhões) de linhas, diferenças muito pequenas dão p-valores próximos de zero. Um p-valor pequeno diz que a diferença provavelmente não é zero, mas não diz se é grande. As conclusões apoiam-se por isso no tamanho do efeito e no seu intervalo de confiança.

2 Funções auxiliares

Correlação rank-biserial (\(r_{rb}\)). Tamanho do efeito do teste de Mann-Whitney. Se \(X\) é um valor ao acaso do grupo 1 e \(Y\) um valor ao acaso do grupo 2,

\[r_{rb} = P(X > Y) - P(X < Y) = 2 \cdot \frac{U}{n_1 n_2} - 1,\]

onde \(U\) é a estatística de Mann-Whitney. Vai de \(-1\) a \(1\); \(0\) quer dizer que nenhum grupo tende a ter valores maiores. \(U / (n_1 n_2)\) é a AUC: a probabilidade de um valor do grupo 1 ser maior do que um do grupo 2 (os empates contam meio). É igual ao delta de Cliff, por isso usam-se os limiares de Romano et al. (2006): \(|r| < 0{,}147\) desprezável, \(< 0{,}33\) pequeno, \(< 0{,}474\) médio, e grande a partir daí.

Intervalo de confiança por bootstrap. Reamostra-se cada grupo com reposição, mantendo o tamanho de cada um (bootstrap estratificado), e calcula-se o efeito em cada réplica. O intervalo a 95% são os percentis 2,5% e 97,5% das réplicas. Não exige nenhuma forma para a distribuição do efeito.

V de Cramér. Tamanho do efeito do teste do qui-quadrado numa tabela \(r \times c\):

\[V = \sqrt{\frac{\chi^2}{n \cdot (\min(r, c) - 1)}}.\]

Vai de 0 (nenhuma associação) a 1 (associação perfeita) e, ao contrário do \(\chi^2\), não cresce com o tamanho da amostra. Numa tabela com 2 colunas, \(\min(r, c) - 1 = 1\), e os limiares de Cohen (1988) são 0,1 pequeno, 0,3 médio e 0,5 grande.

# Correlação rank-biserial: x = valores do grupo 1, y = valores do grupo 2
rank_biserial <- function(x, y) {
  n1 <- length(x)
  n2 <- as.numeric(length(y))               # numérico: n1 * n2 passa o limite dos inteiros
  r <- frank(c(x, y), ties.method = "average")   # empates recebem a posição média
  u <- sum(r[seq_len(n1)]) - n1 * (n1 + 1) / 2
  2 * u / (n1 * n2) - 1
}

# Intervalo bootstrap (percentis) do rank-biserial. Cada grupo é reamostrado com reposição
# separadamente, mantendo o seu tamanho (bootstrap estratificado). Feito à mão em vez de
# boot(), que copia a tabela inteira em cada réplica e fica lento com milhões de linhas.
ic_rank_biserial <- function(x, y, reps = B) {
  set.seed(SEMENTE)
  replicas <- replicate(reps, rank_biserial(x[sample.int(length(x), replace = TRUE)],
                                            y[sample.int(length(y), replace = TRUE)]))
  unname(quantile(replicas, c(0.025, 0.975)))
}

# Classificação do tamanho do efeito (Romano et al., 2006)
magnitude_rb <- function(r) {
  cut(abs(r), c(0, 0.147, 0.33, 0.474, 1), include.lowest = TRUE, right = FALSE,
      labels = c("desprezável", "pequeno", "médio", "grande"))
}

# V de Cramér a partir de uma tabela de contingência
cramers_v <- function(tab) {
  chi2 <- suppressWarnings(chisq.test(tab, correct = FALSE)$statistic)
  unname(sqrt(chi2 / (sum(tab) * (min(dim(tab)) - 1))))
}

# Intervalo bootstrap (percentis) do V de Cramér entre duas variáveis categóricas
ic_cramers_v <- function(x, y, reps = B) {
  dados <- data.frame(x = x, y = y)
  estat <- function(d, i) cramers_v(table(d$x[i], d$y[i]))
  set.seed(SEMENTE)
  res <- boot(dados, estat, R = reps)
  boot.ci(res, type = "perc")$percent[4:5]
}

# Classificação do V numa tabela com 2 colunas (Cohen, 1988)
magnitude_v <- function(v) {
  cut(v, c(0, 0.1, 0.3, 0.5, 1), include.lowest = TRUE, right = FALSE,
      labels = c("desprezável", "pequeno", "médio", "grande"))
}

Porquê o teste de Mann-Whitney (Wilcoxon rank-sum).

  • Compara dois grupos independentes numa variável contínua.
  • Usa as ordens dos valores e não os valores, por isso não exige normalidade e não é dominado por valores extremos. É o teste não paramétrico indicado no T03 para este caso.
  • Alternativa rejeitada: o teste t de Welch. Com esta amostra seria válido pelo teorema do limite central, mas compara médias, que são mais sensíveis à forma da distribuição. Mann-Whitney responde diretamente à pergunta “os Default tendem a ter DTI maior?”.

Pressupostos.

  1. Observações independentes. Cada linha é um empréstimo diferente. Limitação: não há identificador do mutuário, e estima-se que ~0,5% dos empréstimos sejam de mutuários repetidos (docs/02_preprocessamento/duplicados.md). É uma violação pequena.
  2. Variável pelo menos ordinal. O DTI é contínuo (%, com 2 casas decimais).
  3. Interpretação. Sem mais pressupostos, o teste compara \(P(X > Y)\) com 0,5, que é o que a HA diz. Só seria uma comparação de medianas se as duas distribuições tivessem a mesma forma. As densidades acima têm formas parecidas, por isso a estimativa de Hodges-Lehmann (mediana das diferenças entre pares) pode ler-se como a diferença típica em pontos de DTI.
  4. Empates. O DTI tem muitos valores repetidos, por isso o p-valor usa a aproximação normal com correção para empates (exact = FALSE).

Interpretação.

  • Rejeita-se H0 (\(p\) = 2.4e-11): nos empréstimos em Default, o DTI tende a ser maior.
  • Mas o efeito é desprezável: \(r_{rb} =\) 0.065 (IC 95% 0.045 a 0.084). Escolhendo ao acaso um empréstimo em Default e um Good standing, o primeiro tem o DTI maior em 53.3% dos casos, pouco acima dos 50% que se esperariam sem nenhuma relação. A diferença típica é de 0.81 pontos de DTI (IC 95% 0.57 a 1.06).
  • O gráfico da direita mostra a mesma relação: a taxa de default sobe de forma monótona com o DTI, de 10.7% no quintil mais baixo para 13.9% no mais alto.
  • O que significa para os modelos: o DTI tem informação sobre o risco, mas sozinho separa mal as classes. É de esperar que só seja útil em conjunto com outras variáveis (FICO, taxa de juro, grade).
  • Nota sobre os dados: o DTI máximo é 29.99%. Não há nenhum empréstimo com DTI de 30% ou mais, o que indica um limite da política de crédito nestes anos: os requerentes com DTI mais alto foram rejeitados e não estão na amostra. A relação observada é a que existe entre os aprovados, e pode ser mais fraca do que na população de requerentes (selection bias).
  • Associação, não causalidade: um DTI mais alto está associado a mais default, mas os dados não mostram que o DTI cause o default. Ambos podem depender de outros fatores, como o rendimento ou a situação profissional.

4 Hipótese (b): purpose e default

Enunciado: “Loan purpose affects default risk.”

  • H0: o purpose e o desfecho são independentes (a taxa de default é a mesma em todos os purposes).
  • HA: não são independentes (a taxa de default difere em pelo menos um purpose). Não há direção, porque o purpose é uma variável nominal (as categorias não têm ordem).

Porquê o teste do qui-quadrado de independência.

  • Relaciona duas variáveis categóricas (purpose com 14 categorias e o desfecho com 2).
  • Compara as contagens observadas em cada célula da tabela com as que se esperariam se as duas variáveis fossem independentes: \(E_{ij} = \frac{\text{total da linha } i \times \text{total da coluna } j}{n}\). A estatística \(\chi^2 = \sum (O - E)^2 / E\) é grande quando as contagens se afastam muito das esperadas.
  • Alternativas rejeitadas: o teste exato de Fisher só é necessário com contagens esperadas pequenas (e é muito pesado numa tabela 14 × 2 com 31 mil linhas); uma regressão logística daria a mesma informação com mais pressupostos.

Pressupostos.

  1. Observações independentes, cada uma numa só célula. Cada linha é um empréstimo diferente (com a mesma ressalva dos ~0,5% de mutuários repetidos).
  2. Contagens esperadas de pelo menos 5 em todas as células. Verifica-se abaixo: a menor é 9.7 (renewable_energy), por isso não é preciso juntar categorias.
  3. A correção de continuidade de Yates só se aplica a tabelas 2 × 2, por isso não é usada.

Que purposes se afastam da taxa global? O \(\chi^2\) só diz que há diferenças, não onde estão. Para isso usam-se os resíduos padronizados ajustados da coluna Default: \((O - E) / \sqrt{E (1 - p_{linha})(1 - p_{coluna})}\), que seguem aproximadamente uma normal padrão se H0 for verdade. Positivos querem dizer mais default do que o esperado. Como se olha para 14 purposes ao mesmo tempo, o valor crítico tem a correção de Bonferroni: \(|z| > z_{1 - 0{,}05 / (2 \times 14)}\).

Interpretação.

  • Rejeita-se H0 (\(\chi^2 =\) 338.9, 13 graus de liberdade, \(p\) < 2.2e-16): a taxa de default não é a mesma em todos os purposes.
  • O efeito é pequeno: \(V =\) 0.104 (IC 95% 0.093 a 0.118).
  • Mesmo assim, as diferenças entre categorias são grandes: a taxa vai de 8.4% (major_purchase) a 24.1% (small_business), para uma taxa global de 12.3%. O V é pequeno porque a maior parte dos empréstimos está em purposes perto da média (debt_consolidation sozinho tem 45% do treino), e o V mede a associação no conjunto de todos os empréstimos.
  • Com a correção de Bonferroni, têm mais default do que o esperado: small_business, educational, other; e menos default: car, major_purchase, credit_card. Os restantes não se distinguem da taxa global (moving e wedding ficam mesmo no limite). Categorias pequenas como renewable_energy (79 empréstimos) têm intervalos largos e nada se pode concluir sobre elas.
  • O que significa para os modelos: o purpose é uma variável útil, sobretudo para separar os casos de small_business (risco alto) dos de credit_card e major_purchase (risco baixo). As categorias raras devem ser agrupadas, como já faz o pipeline (OneHotEncoder com frequência mínima).
  • Associação, não causalidade: o purpose é escolhido pelo mutuário, e quem escolhe cada um pode ter um perfil diferente (rendimento, FICO, estabilidade do rendimento). Por exemplo, o risco de small_business pode vir da incerteza do rendimento de um negócio e não do purpose em si. Os dados não permitem separar estas explicações.

5 Hipótese (c): aceites vs rejeitados

Enunciado: “Requested amount differs between accepted and rejected applications” e “Lower risk score implies higher rejection”.

Junta-se o ficheiro de aceites ao de rejeitados, ambos do desenvolvimento. As colunas foram postas com o mesmo nome e a mesma unidade em 02b_dados_testes_hipoteses.ipynb:

Limitações da comparação:

  • O loan_amnt dos aceites pode refletir reduções feitas pela LendingClub (dicionário de dados), por isso não é exatamente o montante pedido.

5.1 (c1) Montante pedido

  • H0: o montante pedido tem a mesma distribuição nos aceites e nos rejeitados.
  • HA: as distribuições diferem. O teste é bilateral, porque o enunciado não indica a direção (“differs”).
  • Usa-se todo o desenvolvimento (2007-06 a 2014-12): o montante não depende da escala do risk score.

Porquê o teste de Mann-Whitney. São dois grupos independentes e uma variável contínua muito assimétrica, com valores extremos nos rejeitados (até 1,4 milhões de USD). Um teste baseado nas ordens não é afetado por esses extremos, ao contrário de um teste de médias. Pressupostos: os mesmos da hipótese (a), com a ressalva da independência acima. Há muitos empates (montantes redondos), tratados pela aproximação normal com correção.

Bootstrap com milhões de linhas. Cada réplica demora cerca de 0,5 s, por isso usam-se 500 réplicas em vez de 2000. Chega: com estes tamanhos o intervalo é muito estreito e a sua 3.ª casa decimal não muda com mais réplicas.

Interpretação.

  • Rejeita-se H0 (\(p\) < 2.2e-16): o montante pedido não tem a mesma distribuição nos dois grupos.
  • O efeito é pequeno: \(r_{rb} =\) 0.197 (IC 95% 0.195 a 0.198). Os aceites tendem a ter montantes maiores: um aceite ao acaso tem um montante maior do que um rejeitado ao acaso em 59.8% dos casos. As medianas são 12 000 USD (aceites) e 10 000 USD (rejeitados).

Esses pedidos nunca podiam ser aceites tal como foram feitos.

6 Tabela consolidada

Comparações múltiplas. Fizeram-se 4 testes. Se cada um usar \(\alpha = 0{,}05\), a probabilidade de pelo menos um falso positivo no conjunto é maior do que 5%. A correção de Holm controla essa probabilidade: ordenam-se os p-valores do menor para o maior e o \(i\)-ésimo é comparado com \(\alpha / (m - i + 1)\), onde \(m = 4\). Dá a mesma garantia que a correção de Bonferroni (\(\alpha / m\) para todos), mas rejeita mais vezes quando há efeitos reais. Os p-valores abaixo já vêm ajustados (p.adjust(..., method = "holm")).

7 Conclusões

  • As quatro hipóteses rejeitam H0, mesmo com a correção de Holm. Com amostras deste tamanho isso era de esperar e, sozinho, diz pouco.
  • Os tamanhos dos efeitos são muito diferentes:
    • o risk score separa fortemente aceites e rejeitados (efeito grande);
    • o montante pedido difere pouco entre aceites e rejeitados (efeito pequeno);
    • o purpose está associado ao default com um efeito global pequeno, mas com categorias de risco muito diferente (small_business quase com o triplo de major_purchase);
    • o DTI quase não separa os Default dos Good standing (efeito desprezável), apesar de a taxa de default subir de forma monótona com o DTI.
  • Para os modelos da Parte 2: nenhuma variável isolada separa bem as classes do default, por isso é de esperar que os modelos tenham de combinar várias variáveis, e que as não lineares (árvores, ensembles) possam ganhar. O purpose deve entrar como categoria, com as raras agrupadas.
  • Limitações comuns:
    • selection bias: o default só se observa nos aceites, e a política de crédito cortou os casos extremos (DTI de 30% ou mais, score abaixo de 612);
    • os dados são observacionais: todas as relações são associações, não causas;
    • não há identificador do mutuário, por isso a independência das observações é aproximada;
    • o montante dos aceites pode ter sido ajustado e a sua data é a de financiamento.
